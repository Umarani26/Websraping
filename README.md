# Simple Webscraper
This project demonstrates how to scrape tabular data from a webpage using Python. Specifically, it extracts two columns (Programming Language and Average Annual Salary) from an HTML table and prints the results neatly.

**Learning Focus**
This repository is part of my continuous learning journey in Python and data analysis. It showcases practical skills in:
•	Web scraping
•	Basic data handling with Pandas

**Features**
•	Uses requests to fetch webcontent
•	Parses HTML with BeautifulSoup4
•	Extracts structured data (rows and columns) from tables
•	Stores results in a Python list for further use
•	Optionally converts the data into a Pandas DataFrame for easy analysis or CSV export
